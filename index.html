    Custom XAUUSD endpoint (broker or provider)

    Header values are stored in this browser only. Never put a broker trading key here — use a read-only market-data key or your own proxy. The endpoint must allow cross-origin (CORS) requests.

    Accepted JSON: an array, or an object with candles, data, result or values. Each candle is either [time,open,high,low,close,volume] or an object with those keys.

    [{"time":1731412800,"open":2601.5,"high":2604.2,"low":2599.8,"close":2603.1,"volume":812}]

    For code-level feeds, register an adapter before the app loads data:

    registerFeed('myBroker',{
  name:'My broker', sym:'XAUUSD', proxy:false,
  host:'api.mybroker.com',
  fetch:async(tf,limit)=>[{t,o,h,l,c,v}] // t = unix seconds
});
    Only real responses are ever shown. If every feed fails, the app shows "No data" or clearly labelled cached candles. It never generates prices or signals.
